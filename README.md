# Hi, I'm Rezk Jörg Sebening 👋

**Automation Developer · Open-Source Maintainer · Process Consultant**

I design and build automation systems, API integrations and software that connect business processes, data and the tools behind them.

A large part of my open-source work focuses on the **n8n ecosystem**. I develop and maintain integrations for SaaS platforms, particularly tools used by agencies, coaches, consultants and service businesses in the DACH market.

I'm the **developer and maintainer of multiple n8n integrations**, including the official integrations for **SalesSuite**, **LearningSuite** and **VibeTrack**.

Today, I apply the same systems-oriented approach to software and automation.

I work primarily on:

## Other n8n Integrations

### [OnePage](https://github.com/rjsebening/n8n-nodes-onepage)

Connects OnePage with n8n to trigger and automate workflows around form submissions and leads.

### [OnePage MCP](https://github.com/rjsebening/n8n-nodes-onepage-mcp)

Connects OnePage's Model Context Protocol capabilities with n8n, enabling AI agents and workflows to interact with OnePage through MCP.

### [Digistore24](https://github.com/rjsebening/n8n-nodes-digistore24)

Connects Digistore24 with n8n for automated workflows around purchases, customers, products and other commerce events.

### [easybill](https://github.com/rjsebening/n8n-nodes-easybill-api)

Integration for automating invoices, customers and other processes through the easybill API.

### [LeadTable](https://github.com/rjsebening/n8n-nodes-leadtable)

Connects LeadTable with n8n for automated lead and sales workflows.

### [MemberSpot](https://github.com/rjsebening/n8n-nodes-memberspot)

Integration for automating workflows around MemberSpot and online academies.

### [Evolution API](https://github.com/rjsebening/n8n-nodes-evolution-api)

n8n integration for WhatsApp automation using the Evolution API.

### [Umsatz.io](https://github.com/rjsebening/n8n-nodes-umsatzio)

n8n integration for Umsatz.io.

Legacy project and predecessor of the current SalesSuite integration.
